# Simko SI for iPhone/iPad (Capacitor 8 shell around https://simkosi.com)

Bundle ID: `com.simkosi.app` · Version 1.0 (build 1) · iOS 15+ · iPhone + iPad · Swift Package Manager (no CocoaPods)

## What's native in this build (to clear App Review 4.2 "minimum functionality")
- Native splash screen and full app-icon set (Assets.xcassets), dark status bar over the reef theme.
- Native offline screen (`www/offline.html`, wired through `server.errorPath`): shows when there's no connection and reloads automatically when the Network plugin reports the connection is back.
- Native haptics on Send / mic (via `@capacitor/haptics`, driven by `/assets/simco-mobile.js` on the site).
- Native share sheet (`@capacitor/share`) behind `navigator.share`.
- Push-ready: `@capacitor/push-notifications` installed and AppDelegate forwards APNs tokens. Turn on the **Push Notifications** capability in Xcode once the Apple account exists (needs an APNs key to actually send).
- Mic/camera/photos permission strings are in Info.plist; `ITSAppUsesNonExemptEncryption = NO`.
- No bounce to Safari for sign-in: inside the app the website hides "Continue with Google" (Google blocks OAuth in embedded web views), leaving email + password sign-in, which works in-app. Sign in with Apple stays hidden until it's configured on the server (see policy notes).
- User agent ends with `SimkoSIApp-iOS` so the website can tell it's running in the app.

## Build on a Mac (needs Xcode 16+ and an Apple Developer account)
```bash
unzip simkosi-ios-capacitor.zip && cd simkosi-ios
npm ci                      # restores node_modules (SPM packages point into it)
npx cap sync ios
npx cap open ios            # opens ios/App/App.xcodeproj
```
In Xcode: App target → Signing & Capabilities → pick your Team (automatic signing), add Push Notifications (optional) → Product → Archive → Distribute App → App Store Connect → Upload.
Do not submit for review until Joseph says so.

## Free build check (no Mac, no Apple account)
`.github/workflows/simkosi-ios-unsigned.yml` builds this project unsigned on a GitHub-hosted macOS runner (free on this public repo) on every push to `cursor/simkosi-store-apps`, runs it in the iPhone and iPad simulators and uploads screenshots + an unsigned .xcarchive as the `simkosi-ios-unsigned` artifact. Unsigned builds can't go on a real iPhone or to App Store Connect.

## Universal links / push (after the Apple account exists)
Copy `entitlements-draft/App.entitlements` (applinks + webcredentials for simkosi.com, aps-environment) via Xcode > Signing & Capabilities, and deploy `../well-known/apple-app-site-association` with the real Team ID.

## Not done here (needs a Mac and the Apple account)
