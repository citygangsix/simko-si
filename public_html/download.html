Simko SI

Get the Simko SI app

Use Simko SI in its own window, with its own icon in your Start menu, Dock or app list. It is the same Simko SI as the website, so your chats and settings are the same everywhere.

On your phone

A computer download is not needed on a phone. Put Simko SI on your home screen instead:

  • iPhone (Safari): tap Share, then Add to Home Screen.
  • Android (Chrome): tap the ⋮ menu, then Add to Home screen or Install app.

You are already using the Simko SI app, so there is nothing to install.

Install in one click (recommended)

Works in Chrome and Edge on Windows, Mac, Linux and ChromeOS. Nothing to download or unzip.

If the button does nothing, look for the install icon (a screen with a down arrow) at the right end of the address bar, or open the browser menu and choose Cast, save and share > Install page as app (Chrome) or Apps > Install this site as an app (Edge).

Safari and Firefox

Safari on Mac

macOS Sonoma or later: open simkosi.com in Safari, then choose File > Add to Dock.

Safari on iPhone or iPad

Tap Share, then Add to Home Screen.

Firefox

Firefox on computers does not install websites as apps. Use the launcher below, or open simkosi.com in Chrome or Edge and install it there.

Or download a small launcher

These open simkosi.com in its own app window using a browser you already have (Edge on Windows; Chrome, Edge or Brave on Mac and Linux, else your default browser). They do not include a browser and do not run anything else on your computer.

Heads-up: the launchers are not code-signed yet, so Windows and macOS warn you the first time. On Windows choose More info > Run anyway; on a Mac right-click the app and choose Open. The one-click install above has no warning.
